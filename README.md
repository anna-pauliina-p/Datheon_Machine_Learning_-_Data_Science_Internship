# Wine Classification and Business Intelligence Project

The global wine industry relies heavily on both sensory evaluation and rigorous laboratory testing to determine quality, origin, and authenticity. This project leverages machine learning on the classic Wine dataset (containing 13 chemical features such as alcohol, flavanoids, color_intensity, and proline) to build robust multi-class classification models.

By predicting whether a wine belongs to Cultivar/Class 0, 1, or 2 based strictly on its chemical profile, this project transforms raw laboratory data into actionable business intelligence for wine producers, regulatory bodies, and distributors.

You can find the PDF-version of this analysis [here](https://github.com/anna-pauliina-p/Datheon_Machine_Learning_-_Data_Science_Internship/blob/main/Wine%20Classification%20and%20Business%20Intelligence%20Project.pdf).


# California Housing Regression & Feature Engineering

The California real estate market is characterized by diverse geographical zones, varying household densities, and substantial fluctuations in property values. This project leverages machine learning regression models on the raw California Housing dataset (featuring attributes such as median income, house age, average rooms, population, and ocean_proximity) to predict median house values.

By transforming raw census and geographic data into precise property valuation metrics, this project bridges technical machine learning performance with actionable business intelligence for real estate developers, property investment firms, and automated valuation models (AVMs).
