# Wine Classification and Business Intelligence Project

The global wine industry relies heavily on both sensory evaluation and rigorous laboratory testing to determine quality, origin, and authenticity. This project leverages machine learning on the classic Wine dataset (containing 13 chemical features such as alcohol, flavanoids, color_intensity, and proline) to build robust multi-class classification models.

By predicting whether a wine belongs to Cultivar/Class 0, 1, or 2 based strictly on its chemical profile, this project transforms raw laboratory data into actionable business intelligence for wine producers, regulatory bodies, and distributors.
